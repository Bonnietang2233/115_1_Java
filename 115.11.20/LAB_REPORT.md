預測與實際的差別：
- 能否編譯：預測「能」，實際能編譯，預測正確。
- 第一次 drill 後 getEnergy()：預測 12，實際是 20，預測錯誤。drill 回傳「成功」，但 getter 讀到的能源、樣本、行動次數都沒變（鑽探後 20/0/0/1）。
- 任務完成後鑽探：預期「任務已停止」，實際「成功」。AI 版 drill 沒有檢查 isStopped()。
- 能源耗盡後無法充電：8 格的車 drill 後，Rover 看到的能源仍是 8，所以 execute(3) 充電回「成功」，本來應該已耗盡、回「任務已停止」。

### E3 一個 HeavyRover 物件裡的兩份狀態（new HeavyRover(20, 0)）

| 動作 | Rover 宣告的那份 能源/樣本/行動 | AI 子類別另外宣告的那份 能源/樣本 | getter 讀到 |
|---|---|---|---|
| 建立 | 20 / 0 / 0 | 20 / 0 | 20 / 0 / 0 |
| drill() | 20 / 0 / 0（沒動） | 12 / 3 | 20 / 0 / 0 |
| execute(1) 探索 | 14 / 2 / 1 | 12 / 3（沒動） | 14 / 2 / 1 |

- getEnergy()、getSamples() 寫在 Rover 裡，讀的是 Rover 那一份。
- AI 版 drill() 改的是子類別自己宣告的那一份。
- 這是同一台車（一個物件）裡有兩份 energy、samples，不是兩台車，也不是覆寫。
- AI 版 drill 也沒有呼叫 countAction，所以行動次數不會增加。
